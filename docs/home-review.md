# 首页设计评审（美图设计室设计专家 · 2026-11-15）

评审对象：home-eval.png（两屏：普通日 / 冬至节日态）

## 专家结论摘要

1. **信息层级**：首屏最大权重给了菜图，但决策依据（食材齐全 / 15 分钟 / 简单）压在卡底、字号最小，3 秒内判断不了"这道菜适不适合我"。
2. **节奏留白**：一屏 5 个模块，模块间距≈卡片内边距，区块之间没有视觉停顿，像"堆"在一起。
3. **字体阶梯**：区块标题不够重、标签行太小、缺料提示不够跳，整体层级扁平。
4. **色彩**：方向对但太安全，橙色只用在角标和导航选中态，没用在需要强调的状态上。
5. **推荐卡内部**：次序对，权重反了（菜图 > 菜名 > 理由 > 决策标签）。
6. **问候区**：每日一句 + 引号 + emoji 是典型"AI 人情味套路"，对核心任务零帮助，把推荐卡往下推。
7. **节日态**：徽章与问候语拼接生硬、文案与推荐菜矛盾（饺子句配羊肉汤）、只有首卡变、节日感不贯穿。
8. **AI 味来源**：每日一句、大圆角柔阴影、★推荐胶囊、"浅橙填充"导航选中态、配色过于"正确"。
9. **差异化**：冰箱推荐逻辑有，但视觉上感受不到（首页看不到冰箱状态入口），和普通菜谱 App 无区别。

## 建议（专家原版）

- P0：推荐卡信息权重重构（状态标签提到菜名旁、橙色胶囊）、砍问候区每日一句、强化区块标题（加橙色锚点）
- P1：缺料信息橙色高亮、加"你的冰箱有 N 种食材 →"状态条、节日态与推荐菜统一
- P2：降圆角/阴影、导航选中态改图标变色+下划线、缺料用暖红 #E85D3F 编码状态

## 我方复核（哪些认、哪些不认）

认：
- 决策标签权重过低（P0-1）
- 区块标题层级太平（P0-3）
- 缺料提示不够跳（P1-4）
- 首页缺冰箱状态条，差异化不可见（P1-5）
- 节日文案与推荐菜错位（P1-6）
- ★推荐胶囊套路化（P2）

不认 / 截图误判：
- "圆角 24px、阴影又大又虚"：真实值是 11px 圆角，卡片无阴影（仅底部导航有），此项不成立
- "砍掉每日一句"：是产品明确要的"温度"，改为压缩到一行、与问候同行，不删
- 导航选中态浅橙填充：现有整体语言，单改一处会与其他页不一致，暂不动

## 待实施清单

1. 推荐卡：状态胶囊（食材齐全/只差X）移到菜名右侧，理由保留，meta 拆成「15 分钟 · 简单」小标签并提亮
2. 只差一样：缺料改橙色 + 加粗，右侧箭头加重
3. 区块标题：字号 +2、加左侧橙色短竖线
4. 首页加冰箱状态条：「你的冰箱有 8 种食材 ›」，点击进食材页
5. 节日态：quote/emoji 跟随实际推荐菜层（饺子→🥟，羊肉汤→🍲）；徽章改为「今天冬至」放在日期旁
6. 问候区压缩为两行内：问候语 + 节日徽章 + 日期一行，每日一句同行或缩进一行，减少垂直占用
