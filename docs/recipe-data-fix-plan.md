# 菜谱数据修复方案

> 背景：`miniprogram/data.js` 硬编码 31 道菜。诊断发现系统性缺陷——食材字典**没有料酒、老抽**，导致 5 道荤菜无去腥手段、红烧类无法上色；另有 7 道荤菜无盐且生抽 ≤12ml，基准味不足。红烧排骨步骤过于简化，照做会翻车。
> 约束：不改 `catalog.js` / 页面逻辑；`node --test tests/prototype.test.js` 必须保持 7/7。

---

## 一、为什么这样改是安全的（测试影响分析）

| 测试断言 | 影响 |
| --- | --- |
| `recipes.length === 31`、id 唯一 | 不增删菜，无影响 |
| `getIngredientGroups([])` 覆盖 = `getIngredientOptions()` | 新食材只出现在 `pantry`，而 `getIngredientOptions` 只收 `required/optional` 的食材 → **不受影响** |
| 食材名（含别名）全局不重复 | 新名称「料酒」「老抽」「冰糖」「八角」字典中不存在 → 无冲突 |
| `image` 文件存在 | 不动 image |
| `steps.length >= 2` | 只增不减 |
| `matchRecipes(['排骨','姜'])[0].id === 'braised-ribs'` | 红烧排骨 id/required 不变 → 通过 |

---

## 二、第一步：食材字典补充（`data.js` 顶部 `ingredients`）

```js
cookingWine: ['料酒', '黄酒', '绍兴酒'],
darkSoy: ['老抽'],
rockSugar: ['冰糖', '黄冰糖'],
starAnise: ['八角', '大料'],
```

> 这四项**只加入 pantry 引用，不加入 required/optional**，因此不会出现在冰箱选择页，也不会改变推荐匹配——它们是"家庭常备"层级，与现有的油盐酱醋同级。

---

## 三、第二步：红烧排骨重写（`data.js:368` 起）

```js
{
  id: 'braised-ribs', name: '红烧排骨', servings: 3, minutes: 60, category: '炖菜', heat: 0,
  image: '/assets/braised-ribs.jpg',
  required: [['ribs', 500, '克'], ['ginger', 10, '克']],
  optional: [['scallion', 1, '根']],
  pantry: [
    ['oil', 15, '毫升'], ['cookingWine', 20, '毫升'], ['rockSugar', 20, '克'],
    ['soy', 20, '毫升'], ['darkSoy', 8, '毫升'], ['salt', 2, '克'], ['water', 700, '毫升']
  ],
  steps: [
    ['焯水去腥', '排骨冷水下锅，加 10 毫升料酒和 2 片姜，大火煮开撇净浮沫（浮沫要撇到汤变清），再煮 2 分钟捞出，用温水冲掉表面残沫并沥干。'],
    ['炒糖色', '小火热 10 毫升油，下冰糖不停搅动，熬到完全融化、冒细密小泡、呈浅琥珀色（约 3～4 分钟）。糖色宁浅勿深，变深褐色会发苦。'],
    ['煎香上色', '立刻倒入沥干的排骨（小心溅油），转中火翻炒约 2 分钟，让每块都裹上糖色，边缘微微焦黄。下姜片、葱段（如用）炒香。'],
    ['加热水炖', '沿锅边淋入 10 毫升料酒、生抽和老抽翻匀，一次性加够 700 毫升热水（必须热水，冷水会让肉质收缩发柴），大火烧开转小火，盖盖焖 40 分钟。中途若水不够，只加热水。'],
    ['调味', '开盖尝汤，按口味补 1～2 克盐。此时肉应熟透：筷子戳入带轻微阻力即合适，能轻松穿透则再炖会失去嚼劲。'],
    ['收汁', '转中大火收汁，期间不停翻动并盯紧锅——糖多极易糊底。收到汤汁浓稠、能挂在排骨上（约 3～5 分钟）即关火，撒葱末出锅。']
  ]
}
```

**关键修复点**：加料酒去腥 → 冰糖炒糖色补香气和颜色 → 老抽补色 → 补盐基准 → 水量 500→700ml → 每步带熟度判据和失败点提示。

---

## 四、第三步：5 道去腥缺陷菜（无料酒也无姜）

修法统一：`pantry` 加 `['cookingWine', 10, '毫升']`（快炒类在腌制或下锅前烹入即可），同时在步骤 body 里补一句"下锅前用料酒和少许淀粉抓匀腌 10 分钟"或"沿锅边烹入料酒"。涉及：

| 菜 | id | 附加修法 |
| --- | --- | --- |
| 西兰花炒鸡片 | chicken-broccoli | 鸡片腌制句补料酒 |
| 甜椒炒里脊 | pork-pepper | 里脊腌制句补料酒 |
| 胡萝卜炒肉丝 | pork-carrot | 肉丝腌制句补料酒 |
| 洋葱炒牛肉 | onion-beef | 牛肉腌制补料酒 + 半茶匙小苏打（可写进 note：更嫩，可不加） |
| 虾仁滑蛋 | shrimp-egg | 虾仁焯水或腌制补料酒 |

---

## 五、第四步：7 道淡口味菜补盐基准

统一修法：`pantry` 增 `['salt', 2, '克']`（2 克是基准，UI 已标"按口味调整"），涉及：肉末烧豆腐、甜椒炒鸡丁、西兰花炒鸡片、甜椒炒里脊、胡萝卜炒肉丝、洋葱炒牛肉、葱姜蒸鳕鱼。其中生抽已 ≥18ml 的菜可不加（本次列表内均 ≤12ml，都加）。

---

## 六、执行顺序与验收

1. 字典补 4 项 → 跑测试（应 7/7）
2. 红烧排骨整块替换 → 跑测试（重点看 `matchRecipes(['排骨','姜'])` 断言）
3. 5 道菜加料酒 + 步骤补句 → 跑测试
4. 7 道菜补盐 → 跑测试（全部 `pass 7 / fail 0` 后才算完成）

**人工验收**：微信开发者工具里打开红烧排骨详情页，确认食材清单出现「料酒 / 冰糖 / 老抽」且带"按口味调整"标注（盐属 tasteSeasonings），份数切换时 700ml 水按比例缩放、糖色用量合理。
